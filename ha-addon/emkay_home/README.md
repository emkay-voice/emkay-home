# Emkay Home – a Home Assistant app (add-on)

The OpenVoiceOS for the house, with every Emkay in it as its satellite – on
your Home Assistant. See [DOCS.md](DOCS.md) and [emkay.ai/home](https://emkay.ai/home/).

Add `https://github.com/emkay-voice/emkay-home` under **Settings → Apps → ⋮ →
Repositories** (Add-ons before Home Assistant 2026.2), then install **Emkay Home**.

Home Assistant OS and Supervised only; on Home Assistant Container or Core,
use the normal installation.
